# Sonified Sudoku

An interactive, sonified 6×6 Sudoku website.

**[Open Sonified Sudoku](https://opensonification.github.io/Sonified_Sudoku/)**

The website is contained in `index.html`, originally supplied as
`Sonified6x6Sudoku-V2pt12.html`. Open it directly in a modern browser to run locally.

GitHub Pages publishes the site automatically whenever changes are pushed to
`main`, using `.github/workflows/deploy-pages.yml`.
